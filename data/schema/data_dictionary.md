## Chunking decisions

### `programs_detailed_boostcamp_kaggle.csv` → exercises chunks

- **Strategy:** one JSONL record per exercise row.
- **Text field:** `f"{exercise_name} | {sets} sets x {reps_display} | intensity {intensity}/10 | equipment: {equipment}"`
- **Skip:** rows where `exercise_name` is null.
- **Clean:** cap `reps_abs` at 3,600 s for time-based rows; cap `sets` at 20.
- **Payload:** `source_table`, `title`, `goal`, `level`, `equipment`, `program_length_weeks`, `exercise_name`, `sets`, `reps`, `is_time_based`, `intensity`.

### `program_summary.csv` → program chunks

- **Strategy:** one JSONL record per program, combining narrative fields.
- **Text field:** `title + description + goal + level + equipment + program_length`
  (from `config.settings.PROGRAM_CHUNK_FIELDS`).
- **Skip:** rows where `description` is null.
- **Payload:** `source_table`, `title`, `goal`, `level`, `equipment`, `program_length_weeks`, `time_per_workout_min`, `total_exercises`.
